## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Where the Heart is: Season 2**. This trainer provides convenience features for the game's relationship-driven progression system. It can adjust relationship and lust values, preserve important story flags, unlock selected progression states, and simplify replaying different romance routes without changing the core visual-novel experience.

**Target Audience:** Players who want to replay romance routes, test alternate choices, explore different endings, or reduce repetitive playthrough requirements in this adults-only visual novel.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

The game is a first-person visual novel rather than an action game. There is no free-roaming movement system or movement-based stat to modify. Navigate using the dialogue interface, available choices, and scene controls.

### Tools & Inventory

There is no conventional inventory, equipment screen, or item-based progression system. The trainer focuses on relationship values, lust values, event flags, and route progression instead of items.

### World & Environment

Progression takes place through scripted scenes, conversations, and choice-based events. Choices can alter relationship development, unlock scenes, and affect later story outcomes. Save before major decisions so different branches can be explored safely.

### Combat & Weapons

The game has no conventional combat system, weapons, enemies, or combat statistics. Combat-related trainer functions are not applicable.

## 🧩 Compatibility & Conflicts

Designed for the Windows PC release of Where the Heart is: Season 2. Use the trainer with the same game version whenever possible. Back up saves before changing relationship values or story flags, and avoid enabling multiple progression options during an active choice sequence. The game supports imported Season 1 decisions and statistics, so keep an untouched save for normal continuation.
